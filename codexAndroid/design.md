# GarageNote プロダクト仕様（SDD / Android）

## 1. プロダクト要件

### 1.1 目標
- 車の維持費・期限を記録／管理できるシンプルなオフラインアプリを提供する
- 給油・整備を素早く入力でき、自動計算で負担を減らす
- 月間コストと傾向を可視化し、支出の全体像を把握できるようにする
- 期限切れを防ぐため、失効前に通知する

### 1.2 非目標（v1）
- バックエンドやクラウド同期は行わない
- 複数車両対応は行わない
- 月間以外の高度な分析は行わない

### 1.3 対象ユーザー
- 1台の車を管理する個人ユーザー

### 1.4 技術スタック（v1）
- Kotlin / Jetpack Compose
- ローカルファーストアーキテクチャ
- バックエンドなし
- オフライン専用
- ストレージ：Room（SQLite）
- 通知：Android Notification + WorkManager

---

## 2. ユーザーストーリー

### 給油記録
- ユーザーとして、給油日・走行距離・給油量・金額・燃料種別を記録し、給油履歴を追跡したい
- ユーザーとして、燃費が自動計算され、実燃費を確認したい

### 整備記録
- ユーザーとして、整備種別・日付・走行距離・金額・メモを記録し、整備履歴を残したい
- ユーザーとして、任意で写真を添付し、領収書などを保存したい

### 期限管理
- ユーザーとして、車検・保険・タイヤ交換の期限を設定し、期限を把握したい
- ユーザーとして、期限前にリマインドされ、失効を防ぎたい

### 月間分析
- ユーザーとして、月ごとの給油費・整備費を見て支出を理解したい
- ユーザーとして、円グラフとトレンドグラフで内訳や推移を見たい

### 通知
- ユーザーとして、期限の30日前に通知を受け取りたい

## 3. ドメインモデル

### Vehicle（単一インスタンス）
- id
- name（任意の表示名）
- createdAt

### FuelLog
- id
- date
- mileage
- fuelAmount
- fuelCost
- fuelType（例：レギュラー、ハイオク、軽油）
- fuelEfficiency（自動計算；走行距離 ÷ 給油量、km/L または L/100km）
- createdAt

### MaintenanceLog
- id
- maintenanceType
- date
- mileage
- cost
- memo（任意）
- photoUri（任意）
- createdAt

### ExpirationItem
- id
- type（VEHICLE_INSPECTION | INSURANCE | TIRE_REPLACEMENT、表示名: 車検日 / 保険 / タイヤ交換）
- expirationDate
- reminderDate（自動 = expirationDate - 30日）
- createdAt

### MonthlySummary（派生ビュー）
- month（YYYY-MM）
- fuelCostTotal
- maintenanceCostTotal
- totalCost

## 4. エッジケース

### 給油記録
- 給油量が0以下の場合は燃費は算出しない
- 走行距離が未入力・不正な場合はバリデーションで保存不可
- 走行距離 ÷ 給油量で燃費を表示（満タン法はv1対象外）

### 整備記録
- 写真の権限が拒否された場合、写真なしで保存可能
- 写真ファイルが大きい場合は警告または圧縮

### 期限管理
- 期限が過去日付でも保存可能だが「期限切れ」として表示
- リマインド日が過去の場合、即時通知または次回起動時に通知

### 分析
- 対象月にデータがない場合は空状態を表示
- 給油または整備の片方のみの場合は部分的に表示

### 通知
- 通知権限が拒否された場合は警告表示し、リマインドを無効化

## 5. MVPスコープ

### 含む
- 給油記録のCRUD
- 整備記録のCRUD（写真は任意）
- 車検／保険／タイヤ交換の期限管理
- 月間分析（給油＋整備）
- 期限30日前のローカル通知
- Roomによるローカル保存

### 含まない
- 複数車両対応
- クラウド同期／バックアップ
- 高度な分析（年次推移、予測など）
- エクスポート／インポート

## 6. UI仕様（画面要件）

### 共通
- 画面は下部タブで切替（記録 / 期限 / 分析 / 設定）
- 主要操作は右上 or リスト上部の「追加」ボタン
- 編集/追加画面は「キャンセル」「保存」を並列配置

### 記録タブ（Logs）
- 給油記録と整備記録を同一画面にセクション分割表示
- 給油一覧には日付、走行距離、金額/給油量、燃費、単価を表示
- 整備一覧には日付、整備種別、金額、走行距離を表示
- セルタップで詳細へ遷移

### 給油詳細 / 追加 / 編集
- 詳細: 日付、走行距離、給油量、金額、燃料種別、燃費を表示
- 追加/編集: 日付、走行距離、給油量、金額、燃料種別を入力
- 燃料種別は選択式チップ（レギュラー / ハイオク / 軽油）
- 戻るボタンで詳細から前画面へ戻れる

### 整備詳細 / 追加 / 編集
- 詳細: 日付、整備種別、走行距離、金額、メモ、写真（任意）
- 追加/編集: 日付、整備種別、走行距離、金額、メモ、写真（任意）
- 整備種別は選択式チップ（車検日/保険/タイヤ交換/自動車税/その他）

### 期限タブ（Expiration）
- 期限カードで「車検日 / 保険 / タイヤ交換」を表示
- 期限が過去なら「期限切れ」、未来なら「残りX日」
- 編集画面で期限日を入力し保存

### 分析タブ（Analytics）
- 月間合計（給油/整備/合計）を表示
- 月間平均燃費を表示（燃費単位は設定に従う）

### 設定タブ（Settings）
- 通知ON/OFF（Android 13+ は権限リクエスト）
- 燃費単位の切替（km/L ↔ L/100km）
- 設定初期化ボタン
