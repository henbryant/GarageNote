# QA Checklist (Manual)

## 起動
- [ ] `cd mobile && npm run android` でAndroid起動
- [ ] `cd mobile && npm run ios` でiOS起動（macOSのみ）
- [ ] `cd mobile && npm run web` でWeb起動（簡易確認）

## 初期表示
- [ ] 空データ時に各タブで空状態が表示される
- [ ] 設定タブで通知警告が正しく出る（未許可時）

## 給油記録
- [ ] 追加 → 一覧に表示される
- [ ] 詳細で内容が正しい
- [ ] 初回給油の燃費が `-` になる
- [ ] 編集 → 反映される
- [ ] 削除 → 一覧から消える

## 整備記録
- [ ] 追加 → 一覧に表示される
- [ ] 詳細で内容が正しい
- [ ] 編集 → 反映される
- [ ] 削除 → 一覧から消える

## 期限管理
- [ ] 車検/保険/タイヤの期限を保存できる
- [ ] 期限切れが「期限切れ」表示になる
- [ ] 未来日が「残りX日」表示になる

## 通知
- [ ] 通知ON/OFFでスケジュールが切り替わる
- [ ] 期限30日前に通知が発火する（端末時間変更で検証可）
- [ ] 通知権限が拒否された場合はONにできない

## 分析
- [ ] 月間費用が正しく集計される
- [ ] 円グラフが内訳に応じて変化する
- [ ] 月次トレンドが時系列に表示される
